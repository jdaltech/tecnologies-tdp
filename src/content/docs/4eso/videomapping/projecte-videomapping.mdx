**2. Investiga el concepte i el programari gratuït**
- **Definició:** Cerca què és el *videomapping* (o *projection mapping*) i explica amb les teves paraules en 3 o 4 línies en què es diferencia d'una projecció de cinema tradicional sobre una pantalla plana.
- **Eines existents:** Busca 3 programes gratuïts o de codi obert que s'utilitzin per fer videomapping (per exemple: *MapMap, HeavyM Free, LPMT, Splash, VPT 8*...) i anota a la taula per a quin sistema operatiu serveixen i què permeten fer.

**3. Analitza 3 exemples reals en vídeo**  
Busca a YouTube o Vimeo tres vídeos que encaixin amb aquestes categories i enganxa'n els enllaços al document:
- **Vídeo 1 (Gran format):** Una projecció espectacular sobre la façana d'un edifici històric o monument.
- **Vídeo 2 (Complex / Objectes):** Projecció sobre cotxes, escenaris teatrals o estructures en moviment.
- **Vídeo 3 (Senzill amb caixes):** Busca *"cardboard box projection mapping"*. Observa com es projecta sobre caixes de cartró apilades, perquè serà el nostre punt de partida a l'aula.

**4. Deducció dels requisits tècnics**  
A l'últim apartat del document, escriu **3 condicions indispensables** que necessitarem a l'aula (il·luminació de la sala, color de les superfícies, posició del projector, fons de la imatge...).

**1. Redacta el teu Prompt inicial per a Gemini**  
Obre **Gemini** i demana-li que programi una aplicació web autocontinguda per fer videomapping. Pots fer servir aquesta plantilla com a base, recordant posar-hi **el teu nom**:

```text
Actua com a desenvolupador web. Crea una aplicació autocontinguda en un sol fitxer HTML (amb CSS i JavaScript pur) per fer videomapping educatiu al navegador.
Requisits obligatoris:
1. El títol visible del panell d'eines ha de ser "VideoMapping de [EL TEU NOM]".
2. El fons de pantalla ha de ser negre pur (#000000).
3. Ha de permetre afegir múltiples capes rectangulars ("Quads") i arrossegar-les pel centre per moure-les.
4. Cada capa ha de tenir 4 cercles a les cantonades que es puguin arrossegar amb el ratolí per deformar la perspectiva (aplicant transformacions CSS matrix3d / homografia).
5. Per a cada capa seleccionada, he de poder triar un color sòlid o carregar una imatge/vídeo local des del meu ordinador que s'adapti al 100% dins la forma.
6. Afegeix la tecla drecera 'H' per amagar el menú, els cercles de control i el cursor del ratolí quan activi el mode projecció.
```

**2. Desa el codi com a fitxer `.html` i executa'l**
1. Copia tot el codi que t'hagi generat Gemini.
2. Obre un editor de text pla (Bloc de notes, VS Code, TextEdit en text pla o Caret en Chromebook).
3. Enganxa el codi i desa'l amb el nom **`videomapping_elteunom.html`** (assegura't que l'extensió sigui `.html` i no `.txt`).
4. Fes doble clic sobre el fitxer per obrir-lo amb el navegador (Chrome, Edge o Firefox).

**3. Prova, detecta errors i millora l'aplicació (Iteració)**  
Comprova si l'aplicació fa tot el que li has demanat. Si alguna cosa falla (per exemple, no et deixa esborrar una capa, la imatge queda retallada o es bloqueja en sortir del mode projecció), torna a escriure a Gemini explicant l'error exacte perquè et doni el codi corregit.

## Sessió 3: Caixes, calibratge i continguts

<div class="vm-meta-row">

**1. Prepara l'estructura física de caixes**
- Combina 2 o 3 caixes de diferents mides per crear un volum interessant (esglaonat, en relleu o en angle).
- **Color de les cares:** Si les caixes són de cartró marró fosc, folra les cares visibles amb **folis blancs**. El blanc reflecteix molt millor la llum del projector.
- **Fixació:** Enganxa la base de les caixes a la taula amb cinta de pintor perquè no es moguin ni un mil·límetre durant el calibratge.

**2. Connecta el projector i mesura l'espai**
1. Connecta l'ordinador al projector i selecciona el mode **«Estendre pantalla»** (`Windows + P`).
2. Arrossega la finestra del navegador amb la teva app cap a la pantalla del projector i prem **`F11`** per posar-la a pantalla completa.
3. Mesura la distància entre el projector i les caixes i anota-la al Google Docs de la Sessió 3.

**3. Calibra els vèrtexs i afegeix continguts (Imatges o p5.js)**  
Arrossega les 4 cantonades de cada capa fins que coincideixin exactament amb les arestes físiques de les caixes. Després, assigna a cada cara una imatge, un vídeo en bucle o una animació amb **p5.js**.

:::tip[Repte creatiu: Codi p5.js]
Si la teva app suporta codi `p5.js` en mode instància, prova d'enganxar aquest codi per projectar una animació geomètrica generada per programació (et servirà de preparació per a Processing):
:::

```javascript
p.setup = function() {
  p.createCanvas(400, 400);
};

p.draw = function() {
  p.background(10, 15, 30, 35);
  p.noFill();
  p.stroke(0, 255, 170);
  p.strokeWeight(4);
  let mida = 160 + p.sin(p.frameCount * 0.06) * 120;
  p.rectMode(p.CENTER);
  p.push();
  p.translate(200, 200);
  p.rotate(p.frameCount * 0.02);
  p.rect(0, 0, mida, mida);
  p.pop();
};
```
